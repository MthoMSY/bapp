# Front end for the budget app

## Tech stack
- React
    - react is based on client side rendering (single page application SPA)
    - react interacts with api to update state of webpage and therefore only update portion of the webpage and not the whole webpage
    - results in better performance
    - mobile application development with React Native
    - can be combined with any tech stack
    - JSX, allows to embed html to be embedded in your Javascript components
- Vite
    - use vite to create my react app
    - main.tsx is entry point of application
